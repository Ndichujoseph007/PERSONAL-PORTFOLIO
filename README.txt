NDICHU JOSEPH — PERSONAL PORTFOLIO
=================================

HOW TO OPEN
1. Extract the NDICHU-PORTFOLIO folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.

FOLDER GUIDE
- index.html: page structure and content
- css/style.css: colours, typography, layout and component styling
- css/responsive.css: tablet and mobile layouts
- css/animations.css: reveal and floating animations
- js/script.js: mobile menu, active navigation, reveal effects and email form
- assets/images/: profile image assets
- assets/cv.pdf: add your CV here when ready

PERSONALISE BEFORE PUBLISHING
1. Replace assets/images/profile-placeholder.svg with your own portrait.
   Save your image as profile.jpg, then update the image src in index.html
   from "assets/images/profile-placeholder.svg" to "assets/images/profile.jpg".
2. Add your CV as assets/cv.pdf.
3. Replace every https://github.com/ placeholder URL with your actual GitHub profile
   or the relevant project repository URL.
4. Add your institution name and any verified education details in the Journey section.
5. Update project descriptions and statuses as the projects progress.

CONTACT FORM
The form currently opens the visitor's default email application using a mailto link.
It does not submit to a server. A backend or form service will be needed for a
fully hosted form that works without the visitor's email application.

NOTE
The portfolio describes projects and skills as learning/in-progress where appropriate.
Update those statements as your work develops. Do not publish placeholder links or
credentials as if they were real.
